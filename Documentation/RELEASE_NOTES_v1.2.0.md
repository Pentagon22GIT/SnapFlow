# SnapFlow v1.2.0

## 共有境界につまみを追加

分割したウィンドウの境目へ、WindowsやiPadOSに近い操作感のリサイズつまみを追加しました。つまみとガイドはマウスへ直接追従するため、YouTubeなど重いウィンドウの描画が遅れてもガイド自体は影響を受けにくくなります。

## ドラッグ中の表示を選択可能

- 軽量: すべてアイコンで表示
- 標準: 操作中のウィンドウだけ内容を表示
- すべて表示: すべてのウィンドウ内容を表示

初期設定は「標準」です。アイコン表示の対象は操作終了まで実際にはリサイズしません。新しい画面キャプチャや権限は使用しません。

## 負荷と安全性の改善

ドラッグ中の実リサイズは古い要求を溜めず、常に最新の目標へ更新します。操作終了後の最終補正とキャンセル復元は一時的なブラー表示の裏で行います。全対象の位置とサイズを確認し、失敗した場合は操作前の状態へ戻します。

## 設定画面を整理

設定名と説明を短くし、初めて利用する人にも結果が分かりやすい表現へ変更しました。また、設定画面を初めて開いたときに最下部が表示される場合がある問題を修正しました。
