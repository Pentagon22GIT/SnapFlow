# SnapFlow v1.2.0 Validation Record

検証基準日: 2026-08-07

## この修正版で完了した確認

- 元のv1.1.1プロジェクト全体を基準にした差分確認
- Swiftソースの構文ツリー解析
- 3段階表示モードに「連動側だけ実表示」の状態が存在しないことのテスト追加
- 左右、三分割、四分割の共有境界をまとめる純粋ロジックのテスト追加
- 三分割の横線が分割側だけに留まり、四分割の一致した横線が全幅へ統合されるテスト追加
- 切断済みウィンドウ間につまみを作らないテスト追加
- 両側の最小長を守る境界範囲テスト追加
- マウス座標から全参加ウィンドウを同じ境界へ揃えるテスト追加
- 外部Swift Package、ネットワーク処理、画面キャプチャ処理を新規追加していないことの静的確認
- 仮想表示対象がドラッグ中のAXリサイズ要求から除外されるフロー確認
- キャンセル世代より古い連続リサイズ要求を破棄するフロー確認
- macOSの初回コンパイルで検出された共有線の範囲式を、改行解釈に依存しない上下限変数へ修正
- 前面ウィンドウで覆われた区間だけを共有辺から差し引く純粋ロジックのテスト追加
- 完全に覆われた共有辺へ入力区間を残さないテスト追加
- 6ptずれた左右の横線を一本へ統合しない回帰テスト追加
- 古いWindow Server IDからPIDと現在フレームで参加ウィンドウを復元するテスト追加
- 同一PID・同一フレームで参加ウィンドウを特定できない場合に安全側で入力を作らないテスト追加
- 共有境界グラフから前面化するスナップグループだけを抽出するテスト追加
- 復帰設定が親の連動リサイズと復帰トグルの両方がONの場合だけ有効になる組み合わせテスト追加
- 有効なWindow Server IDが同一PID・同一形状の曖昧候補より優先される回帰テスト追加
- Window Server IDが同一PID内の別形状へ再利用された場合、現在フレームと一致する候補へ安全に戻る回帰テスト追加
- 外部ウィンドウが前面側の参加者だけと重なる場合は不要なAXRaiseを行わず、後方参加者を覆う場合だけ前面化が必要になるZ順テスト追加
- 通常クリック経路から`cancelAllFrameOperations`と`detachedConnections`更新へ到達しないことを静的確認
- 覆われた共有辺区間を実際の`ResizeHandleDescriptor`へ分割し、透明な入力パネルを生成しない接続を確認
- 前面化順序を既存のZ順を保った追従側の後方から適用し、クリック対象を最後に上げることを静的確認
- 遮蔽再試行と前面化後更新が表示世代不一致時に破棄されることを静的確認

## macOS実機で必須の確認

この記録だけで動的検証を完了扱いにはしません。公開前にmacOS 13以降で次を確認します。

- `swift test`
- Community版と公式版のビルド
- 左右、上下、三分割、四分割の各つまみ
- 共有辺全体の判定帯と、T字・十字交差点のドラッグ方向判定
- 軽量、標準、すべて表示の各モード
- YouTube、Discord、Finder、ブラウザでの連続操作
- 高速ドラッグ、Esc、Space変更、画面構成変更、対象ウィンドウ終了
- 確定失敗時に全対象が操作前へ戻ること
- MouseUp後の最終補正とEscによる復元で、ライブ表示対象へ新しいブラーが追加されないこと
- 復帰設定OFFでは離脱後に戻しても再接続せず、ONでは同じドラッグ中だけ再接続できること
- 初回の設定画面が最上部から表示されること
- 別ウィンドウを共有辺の一部へ重ねると、覆われた区間でクリックが貫通しないこと
- 共有辺を完全に覆うとつまみが消え、背後の入力を奪わないこと
- 設定画面の表示中はつまみが消え、閉じるか最小化すると安全に再計算されること
- 高さが異なる四分割の左右の横線は独立し、高さを一致させると一本になること
- 操作せず待機してもつまみが周期的に消えず、ウィンドウ移動後も正しい位置へ追従すること
- スナップ確定後、同じグループが前面へまとまり、今回操作したウィンドウが最前面になること
- 同じ画面上の無関係なウィンドウは前面順序を変更されないこと
- 連動リサイズOFF時に表示モードと復帰設定が無効・減光され、保存した選択自体は失われないこと
- 許容率が親トグルの外に表示され、連動リサイズOFFでも操作できること
- 機能を一時停止して再開した直後につまみが再計算されること
- 通常クリックを連続してもスナップ確定、連動リサイズ確定、Undo履歴が中断されないこと
- 接続グループがすでに前面の場合、クリックしてもつまみが点滅・再配置されないこと
- 前面化設定をOFFにすると、通常クリックで接続ウィンドウを一緒に上げないこと
- 別ウィンドウを一瞬重ねてクリックしても接続が恒久解除されず、重なりを外すとつまみが復帰すること
- 既存v1.1.1設定を保持した更新
- Accessibility以外の新しい権限を要求しないこと
