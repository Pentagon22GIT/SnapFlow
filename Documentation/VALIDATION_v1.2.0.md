# SnapFlow v1.2.0 Validation Record

検証基準日: 2026-08-06

## この修正版で完了した確認

- 元のv1.1.1プロジェクト全体を基準にした差分確認
- Swiftソースの構文ツリー解析
- 3段階表示モードに「連動側だけ実表示」の状態が存在しないことのテスト追加
- 左右、三分割、四分割の共有境界をまとめる純粋ロジックのテスト追加
- 三分割の横線が分割側だけに留まり、四分割の一致した横線が全幅へ統合されるテスト追加
- 切断済みウィンドウ間につまみを作らないテスト追加
- 両側の最小長を守る境界範囲テスト追加
- マウス座標から全参加ウィンドウを同じ境界へ揃えるテスト追加
- 外部Swift Package、ネットワーク処理、画面キャプチャ処理を新規追加していないことの静的確認
- 仮想表示対象がドラッグ中のAXリサイズ要求から除外されるフロー確認
- キャンセル世代より古い連続リサイズ要求を破棄するフロー確認
- macOSの初回コンパイルで検出された共有線の範囲式を、改行解釈に依存しない上下限変数へ修正

## macOS実機で必須の確認

この記録だけで動的検証を完了扱いにはしません。公開前にmacOS 13以降で次を確認します。

- `swift test`
- Community版と公式版のビルド
- 左右、上下、三分割、四分割の各つまみ
- 共有辺全体の判定帯と、T字・十字交差点のドラッグ方向判定
- 軽量、標準、すべて表示の各モード
- YouTube、Discord、Finder、ブラウザでの連続操作
- 高速ドラッグ、Esc、Space変更、画面構成変更、対象ウィンドウ終了
- 確定失敗時に全対象が操作前へ戻ること
- MouseUp後の最終補正とEscによる復元で、ライブ表示対象へ新しいブラーが追加されないこと
- 復帰設定OFFでは離脱後に戻しても再接続せず、ONでは同じドラッグ中だけ再接続できること
- 初回の設定画面が最上部から表示されること
- 既存v1.1.1設定を保持した更新
- Accessibility以外の新しい権限を要求しないこと
