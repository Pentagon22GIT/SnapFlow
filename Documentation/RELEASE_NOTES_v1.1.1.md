# SnapFlow v1.1.1

SnapFlow v1.1.1は、v1.1.0で追加した連動リサイズのウィンドウ前後関係を修正するパッチリリースです。

## Fixed

- 連動リサイズ後、連動先ウィンドウが途中で重ねた別ウィンドウの背後に残る問題を修正しました。
- 実際にリサイズされ、共有辺を維持できた連動先だけを前面へ戻します。
- 最後にユーザーが操作したウィンドウを前面へ戻し、操作対象を最上位に維持します。
- 連動先アプリをアクティブ化せず、キーボードフォーカスを奪わない方式にしました。

## Compatibility

- 通常のスナップ、動的スプリット、侵害率、離脱判定、仮想ボックスおよびドラッグ中の更新頻度は変更していません。
- ネットワーク通信、外部依存関係、Accessibilityおよび画面収録権限の用途に変更はありません。

## Version

- Version: `1.1.1`
- Build number: `3`
- Minimum macOS version: `13.0`
