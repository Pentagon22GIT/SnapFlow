# SnapFlow v1.2.1

v1.2.1は、スプリットグループの前面化と共有境界のつまみ表示を安定させる修正版です。新しい権限、ネットワーク通信、外部依存関係は追加していません。

## クリック時のグループ前面化

スナップ済みウィンドウの通常クリック直後は、macOS側のZ順更新がまだ確定していない場合があります。v1.2.1では短い確定待ちの後に一度だけウィンドウ一覧を取得し、現在も接続されているグループだけを判定します。

前面化が必要な場合は追従側を先に、クリック対象を最後に上げます。その後に結果を確認し、まだ前面へそろっていない場合だけ一度再試行します。保留要求は常に最新一件だけを残すため、連続クリックで処理を蓄積しません。すでにグループ全体が前面ならAXRaiseと追加の遮蔽更新を行いません。

## 共有境界のつまみ表示

つまみは常時判別できる控えめな表示とし、操作意図に応じて明瞭になります。

- 待機時: 45%
- マウス接近時: 92%
- ドラッグ中: 100%
- 初回の遮蔽確認中: 18%、入力無効

遮蔽されていないつまみは同じ識別子とパネルを維持し、不要な再生成を避けます。共有辺の一部でも別ウィンドウが覆っている場合は、その境界の表示と入力領域を全体ごと除去します。残った区間へつまみが逃げないため、間にあるウィンドウを越えて参加ウィンドウだけを前面化する操作を防げます。一時的に遮蔽情報を取得できない場合は直前の確認済み表示を入力無効で維持し、初回だけ安全な薄い基本形状を表示します。

さらにMouseDown直前に最新のWindow Server情報を一度だけ再検証します。表示更新との間に外部ウィンドウが重なった場合も、AXRaiseや連動リサイズを開始せず、最新の遮蔽表示へ更新します。

短時間の遮蔽再試行は6回で停止します。取得不能が続く場合は既存の1秒リカバリだけで確認するため、専用の再試行処理が500ms間隔で継続することはありません。

## 安全性と互換性

- 定期監視の頻度を増やしていません。
- 前面化処理は最新一件、最大二回のAXRaise試行に制限しています。
- 一時的なZ順や遮蔽から恒久的な接続状態を変更しません。
- 画面画像、ウィンドウ内容、入力文字列を新たに取得しません。
- 既存のv1.2.0設定を引き継ぎます。
